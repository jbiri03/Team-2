## HackScout

Find hackathons by topic, keyword, location, date, format, cost, eligibility, and team rules. View event details and official links, save events, include closed listings, or submit an event for review.

## Event suggestions

Visitors can submit an event name and website using **List an event**. Suggestions are saved to Supabase in `public.event_suggestions` with a `pending` status; they are not published automatically. Review submissions in Supabase **Table Editor**.
